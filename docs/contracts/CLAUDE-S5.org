* Boundary and invocation
All changes are unstaged. No live registry, pipe, data root or deployment wrapper
was operated. Runtime is supplied through EH5_RUNTIME, never embedded in a
repository file. Run each command serially from the repository root; retain the
complete stdout/stderr and owned-job cleanup tail. Do not run matrix workers or
background test jobs. Private HKCU is unavailable in the worker sandbox.

The standalone private entry point is windows/scripts/private-host-bundle.ps1.
Pack requires a new immutable directory and copies the host, policy/engine
repository and read-only substrate dependencies. Deploy/Rollback/Recover are
foreground scoped tests, not live pointer installers. They require explicit
private key/pipe/data names, and stop every process when their lifetime ends.
Cycle runs old -> new -> old. Old/new may contain the same adapter executable:
mode=native runs native decisions; mode=policy enables all five S4 switches.
This is a native-policy reference, not a claim to have built a pre-S3 executable.
