Derivation of golden/edit-e2e.golden (mock host) and golden/edit-wine.golden
==========================================================================
PROVENANCE (honest statement): the golden was FIRST GENERATED from a run of the
native implementation (NELISP_TSF_UPDATE_GOLDEN=1) and then reviewed line by
line against windows/src/text_service.cpp (ts.cpp below).  It is therefore
only as independent as that review; the hand-derivation below is the check.
Lines the C++ cannot dictate (mock artifacts) are marked [MOCK].

edit-wine.golden (real wine msctf): RequestEditSession(SYNC|RW=7) reaches our
DoEditSession, GetSelection reaches the store (lock>0, getsel>0), and the
direct commit then fails with E_NOTIMPL (0x80004001) because wine's
ITfRange::SetText is a stub (design doc section 0); settext=0 at the store.
The COUNTERS line (lock=1 getsel=1) is wine behaviour, not C++-derived.

NOT covered / known gaps vs the C++ lines above: registration_target branch
(2951-2960), PublishCaretRect (207-240), ending-composition list in the core
(done by the shim), engine segments from TLV.
