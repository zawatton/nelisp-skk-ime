#+TITLE: LF1 standalone dictionary experiment

This library/bench is independent of the core. See
../../docs/design/local-first-conversion.org for semantics, measured results,
limitations, proposed parity tests and rollout. No live files are read.
user-copy.jisyo is a synthetic fixture copied to the build dir before use.
Do not point it at a live user jisyo or its journal. Pass all input paths.

* Reproduce (PowerShell, repository root)
Set $runtime to the user-provided NeLisp executable; set $notesRoot to the
Notes root. Neither is embedded in repository code. Build/gate logs and raw
traces remain under build/, not in production source.

#+begin_src powershell
cmake -S windows -B build/w -G "Visual Studio 17 2022" -A x64
cmake --build build/w --config Release
ctest --test-dir build/w -C Release
$dictionary = Join-Path $notesRoot 'assets/ddskk/SKK-JISYO.L.utf8'
powershell -NoProfile -ExecutionPolicy Bypass -File windows/test-host/bench-conversion-tsf.ps1 -Runtime $runtime -Dictionary $dictionary -BuildDir build/w -Iterations 20 -ColdLoadSleepSec 45
powershell -NoProfile -ExecutionPolicy Bypass -File windows/test-host/bench-conversion.ps1 -Runtime $runtime -Dictionary $dictionary -Output build/w/phases.json -BuildDir build/w -Iterations 3 -Profile -ColdLoadSleepSec 45
$data = Get-Content build/w/phases.json -Raw | ConvertFrom-Json
foreach ($kind in @('plain','okuri')) {
  powershell -NoProfile -ExecutionPolicy Bypass -File windows/test-host/summarize-conversion-profile.ps1 -Trace (Join-Path $data.traceDir "$kind-host.log")
}
cmake -S windows/proto -B build/lf1-proto -G "Visual Studio 17 2022" -A x64
cmake --build build/lf1-proto --config Release
ctest --test-dir build/lf1-proto -C Release
build/lf1-proto/Release/local-first-bench.exe selftest build/lf1-proto/selftest
Copy-Item windows/proto/user-copy.jisyo build/lf1-proto/user-copy.jisyo
build/lf1-proto/Release/local-first-bench.exe build $dictionary build/lf1-proto/user-copy.jisyo build/lf1-proto/full.index
build/lf1-proto/Release/local-first-bench.exe bench build/lf1-proto/full.index windows/proto/corpus.utf8 100000
$keys = @(Get-Content $dictionary -Encoding UTF8 | ForEach-Object { if ($_ -match '^([^; ]+) /') { $Matches[1] } })
[IO.File]::WriteAllLines((Join-Path $PWD 'build/lf1-proto/all-keys.utf8'), $keys, [Text.UTF8Encoding]::new($false))
build/lf1-proto/Release/local-first-bench.exe bench build/lf1-proto/full.index build/lf1-proto/all-keys.utf8 100000
$env:HOME=[Environment]::GetFolderPath('UserProfile'); emacs -Q --batch -L framework/src -L engines/lattice/src -l framework/test/nelisp-ime-stateline-test.el -l framework/test/nelisp-ime-stateline-conformance-test.el -f ert-run-tests-batch-and-exit
$env:HOME=[Environment]::GetFolderPath('UserProfile'); emacs -Q --batch -L framework/src -L engines/lattice/src -l engines/lattice/test/nelisp-ime-lattice-test.el -f ert-run-tests-batch-and-exit
#+end_src

If full L is unavailable, use windows/test-host/data/behavior-jisyo.utf8 and
report fixture results separately. LF1 used full L, not this fallback.
