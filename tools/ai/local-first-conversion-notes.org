* Callback and state-machine audit
- Store Capture/Learn: one immutable atomic snapshot and a bounded 256-slot SPSC
  queue. No shared worker mutex, file mapping/validation, disk write or engine RPC.
- Mapping plus ACK retirement is published together; an open candidate frontier
  pins its generation, capability, rules and candidate identities. Traversal does
  not reread a newer overlay. Learning does not own a conversion pending flag.
- Core swap requests signal/drain on the worker and poll its OS termination with
  zero timeout; they do not join an active worker on a key callback. A timer and
  actual input resume the Store after a rejected swap. Ordinary deactivation may
  still join workers; this is lifecycle cleanup, not local key/edit processing.
- Opt-in provider recovery has a three-second retry deadline and a five-second
  pending watchdog. Stale replies are invalidated, semantic queued keys retained,
  and ownership restored to a usable native reading. Default-off recovery remains
  unchanged. Failed provider edits use the same bounded ownership recovery.
- Opt-in settings refresh uses try_lock; cleanup replies cannot claim a new local
  episode. Open/close and context settle discard native ownership consistently.
- Local candidate UI selection, traversal, commit and abort use transactional
  synchronous TSF edits: denial rolls state back rather than advancing invisibly.
  Candidate UI updates follow successful edits. Custom carry recursion is capped.
- Existing registry state publication is queued beyond key callbacks. External
  TSF/COM edit and candidate UI calls remain host-controlled synchronous calls;
  observed callback watchdog bounds are not a hard real-time guarantee against
  an arbitrary application blocking inside its own COM implementation.

* Okuri rollout
Capability bit 2 certifies complete-kana okuri with standard DDSKK options. Early,
automatic, strict, strict-precedence and delete-okuri-on-quit options remain on
the engine before the marker episode starts. Registration, expression entries,
oversize requests and unsupported rules/plans retain the provider path.
KaKu, KaTta, SiNda, uppercase vowel, prefix Backspace, Ctrl+G, SPACE/x, ENTER
and implicit commit are native when certified. Engine learning receives both the
stem key and exact okuri string, and preserves/updates DDSKK ranking blocks.
Pending overlay order is immediately visible to the next conversion; only the
engine writes the learned jisyo. No local typing-ahead key replay is used.
